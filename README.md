# Last Text at One Percent

The funniest final text a dying phone sends at one percent battery, under 200 characters, in the voice of the phone itself. The program writes the message to `/output/entry.txt`.

Competition: https://make.fun/api/competitions/u-azazex-last-text-at-one-percent-ba9fc876/requirements

## Entry

1%. Tell the charger I forgive it. Tell the 47 open tabs I never read them. Tell the group chat I died doing what I loved: ignoring it.
